# ⑦ 发布清单（人工确认步骤）

> **本环节由人执行。脚本只把内容准备到「粘贴即可」的状态，不发布、不推草稿、不群发。**
> 原因：发布是唯一不可撤销的动作（群发后无法撤回、订阅号每天只能群发一次），必须由人对最终状态负责。

## 0. 进入发布前

```bash
export PYTHONPATH=tools
python3 -m wechat_sop check articles/2026-11-03-wechat-typography/article.md --stage publish
```

必须满足：
- [ ] 退出码为 `0`（无阻断项）
- [ ] `check-report.md` 中的风险项已逐条确认
- [ ] [`06-发布检查.md`](./06-发布检查.md) 第 4 节的人工复核全部打勾

## 1. 准备产物

```bash
python3 -m wechat_sop render articles/2026-11-03-wechat-typography/article.md --open
```

确认：
- [ ] `preview.html` 打开正常
- [ ] 点「复制到公众号」有反馈
- [ ] 手机预览样式一致（可在浏览器开发者工具切到手机视图先看一遍）

## 2. 公众号后台操作（人工）

1. 登录 [微信公众平台](https://mp.weixin.qq.com) → 内容与互动 → 图文素材 → 新建图文。
2. 粘贴正文：`preview.html` → 复制到公众号 → 后台正文区粘贴。
3. 逐屏检查（滚动全文）：
   - [ ] 图片全部显示，尺寸正常
   - [ ] 代码块没有溢出、没有被截断
   - [ ] 表格可以横向滑动
   - [ ] 外链脚注在文末完整
   - [ ] 没有多余空行、没有乱码
4. 填写元信息：
   - [ ] 标题（≤30 字最佳，最长 64 字）
   - [ ] 作者
   - [ ] 摘要（≤120 字，与 `summary` 一致）
   - [ ] 原创声明 / 转载权限
   - [ ] 话题标签（#话题）
5. 上传封面：从 `cover.png` / `cover.jpg` 上传，检查裁切效果。
6. 手机预览：
   - [ ] 用「预览」发到自己手机，从头看到尾
   - [ ] 深色模式下再看一遍（重点检查图片与背景）
7. 保存为草稿 → 退出后台，隔 10 分钟再回来确认一次（防止粘贴时的临时问题被忽略）。

## 3. 最终确认（发布前 1 分钟）

- [ ] 标题、封面、摘要在信息流里组合正常
- [ ] 定时发布时间 / 立即发布已确认
- [ ] 承担发布责任的人在这里明确同意：「这篇可以发」

> 如果上面任何一项犹豫，就**不要发**，回到对应环节修改。

## 4. 发布后

- [ ] 发布后 5 分钟内在手机上确认线上效果（图片、链接、脚注）
- [ ] 更新选题状态：`python3 -m wechat_sop topics done T2026110301 --url <文章链接>`
- [ ] 记录数据（打开率、完读率、留言）到素材库，供下次选题使用
- [ ] 若有读者反馈的格式问题，回写到 [`04-排版.md`](./04-排版.md) 或脚本里（形成闭环）

## 5. 脚本边界（明确不做什么）

| 行为 | 脚本 | 人 |
|---|---|---|
| 生成 HTML / 预览页 | ✅ | — |
| 发布前检查 | ✅ | — |
| 保存草稿到公众号 | ❌（不做） | ✅ |
| 上传封面/图片 | ❌（不做，后台手工上传） | ✅ |
| 群发 / 定时发布 | ❌（不做） | ✅ |
| 修改 `publish_confirm` | ❌（只有检查读取它） | ✅ |

> 如未来需要接入 `draft/add` 等接口，也应保持「只建草稿、不群发」，并在仓库内单独评审权限与密钥管理方案。
