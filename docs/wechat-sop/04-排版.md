# ④ 排版规范

> 目标：把 Markdown 稳定地转成「粘贴到公众号后台即可」的 HTML，并且每篇看起来一致。
> 人工确认点：**预览页观感由人确认**；脚本只保证结构合规与参数合规。

## 1. 为什么不能直接用 Markdown 排版

微信公众号编辑器在粘贴时会：
- 剥离 `<style>` 标签、`class`、`id`；
- 重写 `<div>`；
- 丢弃 CSS 变量、`@media`、`position`、`grid`；
- 丢弃 `<img width>` 属性（宽度必须写在 `style` 里）；
- 让外部链接不可点击。

所以唯一稳定的做法是：**每个元素都写内联 `style`，用 `<section>` 组织结构，输出纯正文片段**（不带 `<!DOCTYPE>/<html>/<head>`）。

## 2. 脚本做的事

```bash
export PYTHONPATH=tools
python3 -m wechat_sop render articles/2026-11-03-wechat-typography/article.md --open
```

产出：

| 文件 | 用途 |
|---|---|
| `outline.html` | 纯 `<section>` 正文片段，可手动全选复制，也可用于二次加工 |
| `preview.html` | 带「复制到公众号」按钮的预览页，**推荐用这个** |

预览页的按钮只存在于外壳里，不在被复制的 section 内，所以粘进公众号的是干净正文。

渲染管线：

```
Markdown → 结构解析（标题/段落/列表/引用/代码/表格/图片/分割线）
       → 主题样式（themes/*.json 的每个标签的参数）
       → 元素级渲染（内联 style、<section> 结构、<span leaf>）
       → 公众号适配（外链转脚注、嵌套列表提层、图片宽度内联、代码块卡片、表格横滑）
       → 合规渲染（无 class/id/style 标签/div/var/渐变）
       → HTML 片段 + 预览页
```

## 3. 主题（样式一次性配置好）

主题文件：`tools/wechat_sop/themes/*.json`。内置：

| 主题 | 风格 | 适合 |
|---|---|---|
| `default` | 中性、留白多 | 大多数文章（默认） |
| `serif` | 衬线、杂志感 | 随笔、观点、深度 |
| `tech` | 蓝色系、紧凑 | 教程、工具、技术 |

切换主题：改 `article.md` 的 `theme` 字段，或在命令行 `--theme tech` 临时指定。

主题参数见 [`tools/wechat_sop/themes/README.md`](../../tools/wechat_sop/themes/README.md)：

```json
{
  "name": "default",
  "primary_color": "#07c160",
  "font_family": "-apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif",
  "font_size": "16px",
  "line_height": "1.75",
  "styles": {
    "p": { "margin": "0 0 1.5em", "letter_spacing": "0.5px" },
    "h2": { "font_size": "20px", "font_weight": "700", "margin": "2em 0 1em" }
  }
}
```

**规范值（`theme-lint` 会检查）**：

| 项目 | 允许范围 |
|---|---|
| 正文字号 | 14–18px（推荐 15–17px） |
| 行高 | ≥1.6（推荐 1.7–1.9） |
| H1 字号 | ≤28px |
| H2 字号 | ≤22px |
| 字号梯度 | H1 ≥ H2 ≥ H3 ≥ 正文 |
| 背景 | 不得使用 `linear-gradient` / `radial-gradient` |
| 配色 | 只允许一个强调色 |

```bash
python3 -m wechat_sop theme-lint            # 检查全部主题
python3 -m wechat_sop theme-lint tech       # 检查单个主题
```

## 4. Markdown 里能用的语法

| 语法 | 渲染结果 | 说明 |
|---|---|---|
| `# 标题` | 文章大标题（居中、彩色下划线） | 与 frontmatter `title` 重复时可省略 |
| `## 二级标题` | 章节标题（左侧色条） | 正文主要分节 |
| `### 三级标题` | 子标题 | 少用，层级不要太深 |
| 段落 | `<p>` | 段间留白 |
| `**加粗**` | 强调色加粗 | 每段最多 1–2 处 |
| `*斜体*` | 斜体 | 中文慎用，效果不明显 |
| `` `代码` `` | 行内代码（浅色底、等宽） | — |
| ```` ```lang ```` | 代码块卡片 | 深色卡片、行号、横向滚动 |
| `> 引用` | 引用块（左侧色条 + 浅底） | 金句、原文引用 |
| `- 列表` / `1. 列表` | 项目符号/编号列表 | 嵌套列表自动提层，防粘贴打散 |
| `![说明](images/x.png)` | 图片（满宽、圆角、居中） | 相对路径，alt 必填 |
| `[文字](链接)` | 公众号内链保持可点；外部链接转脚注 | 外链自动编号到文末「参考链接」 |
| `---` | 分割线 | 少用 |
| 表格 | 可横向滑动的表格 | 手机窄屏，列数 ≤4 |
| `\n`（段内换行） | 换行 | — |

**不支持**（做了也不会生效，会被过滤）：HTML 标签、CSS 类、`<iframe>`、视频外链、SVG 交互、渐变背景。

## 5. 粘贴到公众号的操作

1. 打开 `preview.html`（`render --open` 会自动打开）；
2. 点右上角 **复制到公众号**；
3. 打开公众号后台 → 图文素材 → 新建 → 标题填 frontmatter 的 `title`，作者填 `author`，摘要填 `summary`；
4. 正文区域 `⌘/Ctrl + V`；
5. **逐屏检查**：图片是否显示、代码块是否溢出、表格是否能横滑、外链脚注是否完整；
6. 上传封面（见 [`05-配图.md`](./05-配图.md)）；
7. 手机预览一遍 → 人工确认 → 保存草稿。

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 粘贴后图片不显示 | 图片是外链 | 用相对路径本地图；或在公众号后台上传后用素材库图片替换 |
| 图片变成原图大小 | `width` 属性被丢 | 渲染时已内联 `style="width:100%"`；若仍异常，检查是否手改了 HTML |
| 代码块溢出 | 公众号不识别横向滚动 | 缩短行宽；脚本已设 `overflow-x:auto` 并缩小字号 |
| 表格错位 | 列太多 | 改为列表，列数 ≤4 |
| 样式不一致 | 手改过预览页里的 HTML | 只改 `article.md`，重新 `render` |
| 某段字号异常 | 粘贴时带入 Word 样式 | 粘贴前清空格式（先粘到纯文本再复制） |
