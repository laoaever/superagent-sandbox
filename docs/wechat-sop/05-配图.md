# ⑤ 配图规范

> 目标：图文比例合适、图能用、有版权、封面合格。
> 人工确认点：**选图与版权判断必须人工确认**。

## 1. 一张文章需要哪些图

| 位置 | 数量 | 规格 | 说明 |
|---|---|---|---|
| 封面 | 1 张（必填） | ≥900×383（2.35:1）或 ≥900×500，<2MB，JPG/PNG | 公众号首图，决定信息流里的第一眼 |
| 正文配图 | 2–5 张 | 宽 ≥600px，<2MB | 平均每 600–1000 字一张 |
| 示意图/截图 | 按需 | 截图宽度 ≥750px，关键区域不要小于一半 | 代码/工具操作类文章必备 |

**判断标准**：图必须**承担信息**（说明流程、对比数据、展示操作），而不是装饰。配一张与内容无关的风景图，比不配更减分。

## 2. 图片放哪里、怎么引用

```
articles/<日期>-<slug>/
├── images/
│   ├── 01-耗时对比.png
│   ├── 02-预览页截图.png
│   └── 03-...
└── cover.png
```

正文里用相对路径引用，并写 `alt`：

```markdown
![同一篇文章三种方式的排版耗时对比](images/01-耗时对比.png)
```

规则：
1. **必须用相对路径 + 本地文件**。外链图片公众号不接受，脚本也无法检查可用性。
2. **`alt` 必填**，写「这张图在说什么」，不写「图片」。
3. 文件名用「序号-简短中文描述」，保持 `images/` 内按阅读顺序排列。
4. 图片放进 `images/` 后**不再改名**，否则正文引用会断。

## 3. 图片规范

| 项目 | 规范 |
|---|---|
| 尺寸 | 宽度 ≥600px；截图 ≥750px；不用表情包当正文配图 |
| 比例 | 首图横版 2.35:1，正文图 16:9 或 4:3，**全文比例尽量统一** |
| 体积 | 单图 <2MB，整篇 <10MB（超过公众号上传会慢） |
| 格式 | JPG（照片）/ PNG（截图、带文字）/ GIF（动图，仅演示） |
| 文字 | 图内文字 ≥28px（手机上看不清的图等于没配） |
| 风格 | 同一篇文章内配色、字体、边框统一 |
| 隐私 | 打码手机号、真实姓名、内网地址、令牌 |

> 脚本检查项：文件是否存在、宽度是否 ≥300px、`alt` 是否为空、是否有外链图片。

## 4. 封面

封面是唯一「必填」的图，`check` 会阻断缺失。

```bash
# 在 frontmatter 里指定
cover: cover.png

# 或命令行临时指定
python3 -m wechat_sop check articles/2026-11-03-wechat-typography/article.md --cover images/cover-v2.png
```

封面设计要求：
- 主视觉占画面 1/2 以上，不要满屏小字；
- 底部或侧边留出安全区（信息流会裁切）；
- 文字 ≤12 字，字号 ≥48px；
- 与主题色一致（暗色背景 + 主题色标题最常见也最稳）。

## 5. 版权与合规

| 来源 | 是否可用 | 注意事项 |
|---|---|---|
| 自己截图 / 自己拍摄 | ✅ | 注意打码隐私信息 |
| 公共领域 / CC0 | ✅ | 记录来源链接 |
| CC BY / CC BY-SA | ⚠️ | 必须署名，注意 ShareAlike 条款 |
| 企业/别人的图片 | ❌（除非有授权） | 商业公众号被投诉代价高 |
| 搜索引擎直接下载 | ❌ | 多数有版权 |
| AI 生成 | ⚠️ | 确认所用工具允许商用，且不涉及他人形象/风格侵权 |

每张非自制图片在正文图注或文末注明来源与许可，例如：

```markdown
> 图 1：数据来自官方文档（链接），截图自 2026-11-01。
```

## 6. 配图检查

```bash
export PYTHONPATH=tools
python3 -m wechat_sop check articles/2026-11-03-wechat-typography/article.md
```

输出中的图片相关项：

- `image-missing`：正文引用但文件不存在（阻断）
- `cover-missing`：无封面或封面不存在（阻断）
- `image-small`：图片宽度 <300px（阻断，手机上会模糊）
- `image-no-alt`：图片没有说明（风险项）
- `image-external`：使用外链图片（风险项，公众号可能不显示）
- `image-lonely`：全文 0 张正文图（风险项，提示补图）
