# ⑥ 发布前检查清单

> 目标：发布前把所有「会返工/会出事」的问题一次性找出来。
> 一键执行：

```bash
export PYTHONPATH=tools
python3 -m wechat_sop check articles/2026-11-03-wechat-typography/article.md --stage publish
```

脚本会把结果写到文章目录的 `check-report.md`，并给出退出码：

| 退出码 | 含义 |
|---|---|
| `0` | 无阻断项（风险项需人工逐条确认） |
| `1` | 存在阻断项，**禁止发布** |
| `2` | 参数/文件错误（如文件不存在） |

## 1. 分阶段检查

| 阶段 | 命令 | 检查内容 |
|---|---|---|
| 写稿中 | `check ... --stage draft` | 标题、摘要、字数、占位符、标点、中英文间距、敏感词 |
| 发布前 | `check ... --stage publish`（默认） | 以上全部 + 主题、封面、图片、排版合规、发布确认 |

## 2. 阻断项（必须清零，`check` 失败）

| 编号 | 检查项 | 规则 | 修复 |
|---|---|---|---|
| B01 | 标题缺失 | `title` 为空 | 填 frontmatter `title` |
| B02 | 标题超长 | > 64 字（公众号 API 硬限） | 精简标题 |
| B03 | 摘要缺失 | `summary` 为空 | 写一句话摘要 |
| B04 | 摘要超长 | > 120 字 | 精简 |
| B05 | 正文过短 | < 300 字 | 补内容或确认是否误操作 |
| B06 | 正文过长 | > 6000 字 | 拆成系列文章 |
| B07 | 封面缺失 | 无 `cover` 或文件不存在 | 制作并放入封面 |
| B08 | 图片缺失 | 正文引用的图片文件不存在 | 修正路径或补图 |
| B09 | 图片过小 | 图片宽度 < 300px | 换高清图 |
| B10 | 占位符残留 | 仍有 `TODO`、`【待补】`、`{{xxx}}` | 补全后删除 |
| B11 | 主题不存在 | `theme` 不在 `themes/` 中 | 改用内置主题或新增主题文件 |
| B12 | 排版不合规 | `render` 未生成或产物含禁用标签/样式 | 重新 `render` |
| B13 | 发布未确认 | `publish_confirm` 不是 `true` | **人工**确认后改为 `true` |
| B14 | 敏感/违禁词 | 命中 `config/checkwords.txt`，或命中内置的广告法硬禁词（最强、行业第一等） | 改写表述或确认后从词表移除 |

> B13 是最后一道人工闸门：**只有人**能把 `publish_confirm` 改成 `true`。脚本永远不会自动改它。

## 3. 风险项（需要人工逐条确认）

| 编号 | 检查项 | 规则 | 建议 |
|---|---|---|---|
| W01 | 标题偏长 | > 30 字 | 信息流会截断，考虑精简 |
| W02 | 图片无说明 | 图片 `alt` 为空 | 补说明 |
| W03 | 外链图片 | 图片为 `http(s)://` 外链 | 改为本地图 |
| W04 | 无正文配图 | 全文 0 张图 | 补 2–5 张 |
| W05 | 半角标点 | 中文上下文出现 `,` `;` `?` `!` `(` | 运行 `format --write` |
| W06 | 中英文粘连 | 中文与英文/数字之间无空格 | 运行 `format --write` |
| W07 | 未完成标记 | 出现「待补充」「FIXME」「XXX」 | 补全或删除 |
| W08 | 绝对化用语 | 「最好」「第一」「唯一」等 | 广告法有约束，确认属实，否则改写 |
| W09 | 段落过长 | 单段 > 400 字 | 拆分，手机阅读更友好 |
| W10 | 缺少结尾行动 | 末节没有具体行动建议 | 补一句行动 |
| W11 | 素材未登记 | `materials` 字段与正文引用不一致 | 核对素材库 |

## 4. 人工复核清单（脚本查不了，逐条打勾）👤

### 事实与合规

- [ ] 所有数据、案例、引语都有出处，且与原文一致
- [ ] 没有未经授权引用的他人成果、截图、图片
- [ ] 涉及他人的信息已脱敏（姓名/手机号/公司内网）
- [ ] 没有夸大、绝对化承诺（「一定」「唯一」「保证」）

### 观感

- [ ] 手机预览逐屏看过：图片、代码块、表格、脚注都正常
- [ ] 封面在信息流裁切后仍能看懂
- [ ] 标题 + 封面组合有吸引力但不标题党
- [ ] 前 3 段能抓住读者

### 发布信息

- [ ] 标题、作者、摘要、原创声明已确认
- [ ] 留言功能是否开启已决定
- [ ] 定时发布/立即发布已确认
- [ ] 相关话题标签已添加

## 5. 检查报告

`check` 会在文章目录生成 `check-report.md`，形如：

```markdown
# 发布前检查报告

- 文章：articles/2026-11-03-wechat-typography/article.md
- 阶段：publish
- 结论：❌ 存在 2 项阻断问题

## 阻断项（2）
- [B07] 封面缺失：未找到封面文件 cover.png
- [B13] 发布未确认：publish_confirm 尚未设为 true

## 风险项（1）
- [W01] 标题偏长：31 字（建议 ≤30 字）
```

报告中包含具体的修复建议，可直接据此修改。

## 6. 发布（见 [`07-发布清单.md`](./07-发布清单.md)）

检查全部通过后，进入人工发布环节。**脚本不会发布任何内容。**

## 7. 前置条件

- [ ] 正文已定稿
- [ ] 排版已生成（`render`）
- [ ] 配图与封面已就位
- [ ] 你在一个安静的地方，能完整看一遍手机预览
