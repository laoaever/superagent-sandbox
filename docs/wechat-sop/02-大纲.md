# ② 大纲

> 目标：把选题卡变成可写的结构，让「写正文」变成填空而不是重新思考。
> 人工确认点：**大纲必须人工确认后才写正文**。

## 1. 大纲的最小要求

一份可用的大纲必须包含：

1. **标题**（含 2–3 个备选，见第 4 节）；
2. **一句话核心结论**（读者读完能带走的那句话）；
3. **章节列表**，每节写清：要论证什么 → 用什么证据 → 期望读者产生什么反应；
4. **开头钩子**与**结尾行动**（结尾要给读者一个具体动作，而不是「希望对你有帮助」）；
5. **配图计划**（每节是否需要配图、图来源）。

## 2. 用模板起手

不要从空白页开始。按文章类型选模板：

```bash
export PYTHONPATH=tools
python3 -m wechat_sop templates          # 列出可用模板
python3 -m wechat_sop new --topic T2026110301 --template tutorial --slug wechat-typography
```

模板会把骨架、每节的写作提示、frontmatter 字段全部生成到 `articles/<日期>-<slug>/article.md`。

内置模板：

| 模板 | 适用文章类型 | 骨架 |
|---|---|---|
| `观点` | 观点/深度分析 | 钩子 → 现象 → 根源 → 主张 → 证据 → 反方回应 → 行动 |
| `教程` | 操作指南/工具使用 | 钩子 → 你将得到什么 → 前提 → 步骤 1..N → 常见坑 → 行动 |
| `盘点` | 工具对比/清单 | 钩子 → 评选标准 → 条目 1..N（每个：是什么/适合谁/不足）→ 怎么选 → 行动 |
| `复盘` | 案例/数据复盘 | 钩子 → 背景 → 做了什么 → 结果数据 → 关键判断 → 可复用方法 → 行动 |
| `随笔` | 生活/情感/经验分享 | 钩子 → 场景 → 转折 → 思考 → 落点 |
| `通告` | 活动/更新/招聘 | 一句话说清 → 是什么 → 关键信息（时间/地点/条件）→ 怎么参与 |

> 模板是**骨架**不是**剧本**：允许增删章节，但删掉「行动」前先想清楚读者读完要做什么。

## 3. 大纲自检（写正文前必做）

```bash
python3 -m wechat_sop outline articles/2026-11-03-wechat-typography/article.md
```

脚本输出章节树，并给出结构问题提示：

- 章节数 < 3 或 > 8；
- 某一节下没有任何要点（空壳章节）；
- 标题层级跳跃（`#` 直接到 `###`）；
- 某节只有小标题没有内容（正文为 0 字）；
- 缺少开头结论与结尾行动。

脚本是提醒，不替代人判断。**结构问题必须在写正文前解决。**

## 4. 标题的写法

公众号标题决定打开率，但只有 30 字左右的展示位（API 硬限 64 字，展示会在 30 字左右截断）。

做法：
1. 先写 **5 个备选**，不要在第一个标题上打磨；
2. 每个备选包含：人群定位语（可选）+ 核心结论 + 具体锚点（数字、工具名、时间）；
3. 从三个维度打分（1–5）：**具体度**（有没有具体对象/数字）、**信息量**（读完标题能不能知道答案方向）、**可信度**（有没有夸张承诺）；
4. 选总分最高，且**可信度不为最低**的那个。

反面清单（一律不用）：
- 标题党承诺：「看完这篇，你也能月入十万」
- 空词：「干货」「深度好文」「值得收藏」
- 只讲情绪不讲信息：「太真实了」「我终于想明白了」
- 超过 30 字还塞满两个主题

## 5. 大纲文档格式（`outline.md`）

```markdown
# 大纲：公众号排版，别再手调样式了

## 一句话结论
排版应该一次配置、长期复用；每篇手调样式是在浪费写作时间。

## 开头钩子
自测数据：同一篇 2500 字文章，手调 32 分钟。

## 章节
### 1. 你每篇在排版上花了多久？（Hook：实测数据）
- 论证：手调排版耗时与错误率
- 证据：M2026110302 自测数据
- 配图：耗时对比柱状图

### 2. 为什么会这样：样式没有固化
- 论证：每次重新设计 = 每次重新决策
- 证据：三篇旧文的样式差异截图

### 3. 解法：固定主题 + 一键输出 + 检查清单
- 论证：一次配置，长期复用
- 证据：本 SOP 的示例文章

### 4. 落地：一周内跑通的步骤
- 论证：可执行的最小步骤
- 证据：（无，属于行动建议）

## 结尾行动
照第 4 节建好文章目录，用默认主题渲染第一篇。
```

## 6. 人工确认清单 👤

写正文前逐条打勾：

- [ ] 标题 ≤30 字，含具体锚点，无夸张承诺
- [ ] 一句话结论能让读者带走
- [ ] 每节都有「论证 + 证据」两行，没有空壳章节
- [ ] 证据在素材库中有编号（或明确标为「经验」，不编造数据）
- [ ] 结尾有一个具体动作
- [ ] `python3 -m wechat_sop outline` 无结构问题提示
- [ ] 大纲已通过他人（或自己隔一天）确认

## 7. 前置条件

- [ ] 选题已立项（[`01-选题.md`](./01-选题.md)）
- [ ] `article.md` 已由 `new` 命令生成（含 frontmatter）
- [ ] `outline.md` 已填写
